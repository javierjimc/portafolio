Backend · Node.js · PostgreSQL (Neon)

API RESTful segura para gestión de usuarios y datos

Descripción

Diseño y construcción de una API RESTful para gestionar usuarios y tareas, como parte del proyecto integrador de backend. Servidor Express con arquitectura modular (rutas → controladores → servicios → modelos) y persistencia real en PostgreSQL sobre Neon mediante el ORM Sequelize.

Desafío principal

Pasar de un servidor con archivos planos a una arquitectura profesional con base de datos en la nube: modelar tres tipos de relación (1:1, 1:N, N:M), conectar de forma segura a Neon con SSL y mantener respuestas consistentes sin romper la API ante errores o datos inválidos.

Solución propuesta

Arquitectura por capas + Sequelize con asociaciones; validación en dos niveles (express-validator en las rutas y validaciones de modelo); un middleware central que traduce los errores de Sequelize a códigos claros (400 / 404 / 409 / 500), y un formato de respuesta uniforme { status, message, data }.

Herramienta técnica utilizada

Node.js + Express, Sequelize como ORM, PostgreSQL sobre Neon (serverless), express-validator, dotenv y nodemon. Control de versiones con Git y GitHub.

Habilidades técnicas aplicadas

Diseño de APIs REST, modelado relacional con ORM, manejo de errores y validación, arquitectura modular, conexión segura a servicios en la nube y buenas prácticas con Git.

Principales aprendizajes

  • Modelar relaciones (1:1, 1:N, N:M) y resolverlas con un ORM en vez de SQL manual.
  • Separar responsabilidades por capas hace el código testeable y escalable.
  • Centralizar el manejo de errores mejora la consistencia y la experiencia de quien consume la API.
  • Conectar de forma segura (SSL + variables de entorno) y no exponer credenciales en el repositorio.
